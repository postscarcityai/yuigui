Chris opened a Before I go page on TestFlight. It asked "Ship it?" and then asked "Ship it?" again. Ship what?

"I need context and action on the same screen."

The page was right to ask everything at the end. The mistake was where it put the words. The line that says what a question is about lived in an earlier part of the answer, one swipe away. By the time you reached the buttons, it was gone.

## The line comes with the question

Now each question carries the line or picture that came right before it in its own reply. It is drawn above its buttons. You read what it is about, then you tap. Nothing to remember, nothing to swipe back for.

## On the web too

The web stage had the same gap, so it got the same fix. Each question card sits under its subject.

```shot

```

## A rule for agents

Agents get it in the channel guide. A question's title names its subject. Two titles on one page are never alike. A bare "Ship it?" twice is now a mistake an agent can see itself making.
