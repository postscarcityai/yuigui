Chris used the last build for a day and wrote down what bugged him. Build 535 is the answer. Here is each note, with the new screen.

## Decks fill the screen

A deck is no longer a card with dots under it. It is the whole screen, and the drawing morphs from one page to the next.

```shot
/progress/deck-morph-01-dark.webp | Dark mode: the first page of a deck, full screen
/progress/deck-morph-03-dark.webp | Dark mode: the same deck, a later page, the drawing moved on
```

## Home is only your chats

The drawer was too busy. Home now lists your chats and nothing else. Flows and the backlog sit in one short list under Agent, then More. There is no agent roster page to wade through.

```shot
/progress/drawer-calm-after-dark.webp | Dark mode: the drawer, Home showing only chats
/progress/drawer-calm-more-dark.webp | Dark mode: the Agent page with More holding flows and the backlog
```

## Pages are named for what is on them

A side page that said Screen 2 meant nothing. Tabs now read what is on the page: Timer, List, This week.

```shot
/progress/fb-ahcav8vw-tabs-after-dark.webp | Dark mode: tabs named for what each page holds
```

## A question shows what it asks about

On the questions page, each question now carries the line it came from. You no longer guess what Yes refers to.

```shot
/progress/note57356-after-dark.webp | Dark mode: a question with the line it asks about above it
```

## Workouts, with music and edits

Start opens the runner full screen. A small strip plays, skips and pauses your music. Edit changes a move, the sets or the weight while you train, and your agent is told what changed.

```shot
/progress/yui305-music-dark.webp | Dark mode: the workout runner with a music strip
/progress/yui305-edit-dark.webp | Dark mode: the Edit sheet over the runner
```
