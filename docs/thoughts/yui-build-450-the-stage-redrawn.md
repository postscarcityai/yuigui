Build 450 is on TestFlight. It is the first one since 392, so it carries everything in between. The big change is how an answer looks.

## The stage is a blueprint now

Answers draw as thin lines on one clean page. No card around them. Lines like Label: value read as a ledger, with a tick, a dot, an arrow or a cross beside each.

## The menu button wears the agent's name

Top left, the menu button is a pill, and it says who you are talking to. It is there on every screen.

```shot
/progress/feedback-menu-pill-after-dark.webp | Dark mode: the menu pill with the agent's name
/progress/feedback-menu-pill-long-light.webp | Light mode: a long agent name, still one pill
```

## No end screen while the agent is still working

The last page used to show early, while the agent was still answering. Now it waits for the reply that answers you.

