Build 545 is in TestFlight. An agent answers with a film, and it plays full screen. Scene one starts the moment it is written. The rest follow while it plays. Tap the X when you are done.

The pictures come from the same kit as the website, so nothing is fetched while you watch. If you turn on Reduce Motion, you get a still frame for each scene instead, with the words it says.

Want to see what these films can be? Read [Yui draws anything](/thoughts/yui-draws-anything).

```try
/thoughts/yui-draws-anything | How the films are made
/motion | Play all 40 films
```
